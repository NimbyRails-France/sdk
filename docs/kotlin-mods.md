# Créer un mod Kotlin

Ce guide est désormais maintenu dans le [dépôt du wiki officiel](https://github.com/NimbyRails-France/wiki-dev),
page [commencer/installation de l’édition 0.9](https://wiki-dev.nimbyrails-france.fr/version/0.9/commencer/installation).

Le wiki contient les explications, exemples Kotlin et signatures synchronisées
avec les sources du SDK. Ce fichier reste uniquement pour les anciens liens
et les kits hors ligne. Il ne constitue pas une seconde documentation à maintenir.

Options globales et raccourcis du SDK 0.9 en développement :
[guide en français](https://wiki-dev.nimbyrails-france.fr/version/0.9/mods/options) ·
[English guide](https://wiki-dev.nimbyrails-france.fr/en/version/0.9/mods/options).
Déclarer avec `options(...)`, puis lire la valeur typée `.value` dans le mod.
Les raccourcis des fenêtres sont créés automatiquement par `window(...)`.
Dans le jeu, ouvrir **Options → NRF Hub** : **Interface** regroupe les préférences
et **Raccourcis** les raccourcis des fenêtres, classés par mod dans chaque rubrique.
Seules les rubriques utiles apparaissent. S'il n'y a que des raccourcis, ils sont
affichés directement, sans boutons de navigation entre les rubriques.

In the game, open **Options → NRF Hub**: **Interface** contains preferences and
**Shortcuts** contains window shortcuts, grouped by mod in each section.
Only sections with registered settings appear. If there are only shortcuts,
they appear directly, without section navigation buttons.
