# API publique 0.7

NimbyRailsFranceSDK expose uniquement l'[API C++20](cpp-api-reference.md),
accessible par `<nimby/client.hpp>`.

L'ancienne API C publique est retirée. Voir la [migration 0.6 vers 0.7](migration-0.7.md)
pour les remplacements. Les détails C présents sous `nimby/detail/` servent
uniquement au pont interne entre les helpers et la DLL.
